# Седмица 6 — Задачи за затвърждаване

## Задача 1: Клас `Fraction`

Създайте клас `Fraction` (рационално число) с числител и знаменател.
- **Инвариант:** знаменателят не може да бъде 0; дробта винаги е в нормализиран вид (НОД = 1)
- **Оператори:**
  - `+`, `-`, `*`, `/` (и съответните `+=`, `-=`, `*=`, `/=`)
  - `==`, `!=`, `<`, `>`
  - `<<` за отпечатване (формат: `числител/знаменател`)
  - `>>` за четене

**Пример:**
```
Fraction a(1, 2);  // 1/2
Fraction b(1, 3);  // 1/3
std::cout << a + b;  // 5/6
```

## Задача 2: Клас `Date` с оператори за сравнение

Създайте клас `Date` (ден, месец, година) с:
- Оператори: `==`, `!=`, `<`, `>`, `<=`, `>=`
- `operator<<` за отпечатване (формат: `DD.MM.YYYY`)
- `operator++` (prefix) — преминава към следващия ден (с коректна обработка на месеци и години)
- `operator-` между две дати — връща разликата в дни

## Задача 3: Клас `BigInteger`

Създайте опростен клас `BigInteger`, който пази число като масив от цифри (или `char*`).
- **Оператори:**
  - `operator+` — събиране (помислете за пренасяне)
  - `operator==` и `operator<`
  - `operator<<` за отпечатване

> 🧠 **Hint:** Пазете цифрите в обратен ред (единици на позиция 0) — улеснява събирането.

## Задача 4: Клас `String` с оператори

Разширете класа `String` от миналата седмица с:
- `operator+` — конкатенация
- `operator+=` — добавяне на суфикс
- `operator[]` — достъп до символ по индекс (const и non-const)
- `operator==` и `operator<` — лексикографско сравнение
- `operator<<` и `operator>>`

**Пример:**
```cpp
String a("Hello");
String b(" World");
String c = a + b;
std::cout << c;        // Hello World
std::cout << c[0];     // H
```
