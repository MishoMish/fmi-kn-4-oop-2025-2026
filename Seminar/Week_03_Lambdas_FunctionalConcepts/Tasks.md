# Седмица 3 — Задачи за затвърждаване

## Задача 1: Филтриране с ламбда

Дадени са масив от `int` и шаблонна функция `filter`:

```cpp
template <typename T>
int filter(const T arr[], int size, T result[], std::function<bool(const T&)> predicate);
```

Използвайте ламбда функции, за да:
1. Филтрирате само четните числа
2. Филтрирате числата, по-големи от средното аритметично (изчислете го предварително и го capture-нете)
3. Филтрирате числата, делими на дадено число `k` (capture `k`)

---

## Задача 2: Трансформация на масив

Напишете функция `transform`, която приема масив и ламбда и прилага ламбдата върху всеки елемент:

```cpp
void transform(int arr[], int size, std::function<int(int)> func);
```

Приложете последователно:
1. Всеки елемент се увеличава с 1
2. Всеки отрицателен елемент се замества с абсолютната му стойност
3. Всеки елемент се повдига на квадрат

## Задача 3: Ламбда компаратор за структура

Дефинирайте структура `Product` с полета: име (`char[50]`), цена (`double`), количество (`int`).

Напишете функция за сортиране с ламбда компаратор. Сортирайте масив от `Product`:
1. По цена (възходящо)
2. По количество (низходящо)
3. По обща стойност `цена * количество` (низходящо)

## Задача 4: Pipeline от операции

Напишете функция `applyPipeline`, която приема масив и масив от операции (`std::function<int(int)>`) и ги прилага последователно:

```cpp
void applyPipeline(int arr[], int size, 
                   std::function<int(int)> operations[], int opCount);
```

Тествайте с pipeline:
1. `x * 2` → `x + 10` → `x % 100`
