# Седмица 7 — Задачи за затвърждаване

## Задача 1: Обръщане на редове

Прочетете текстов файл ред по ред и запишете в нов файл редовете в **обратен ред** (последният ред става първи).

**Вход (input.txt):**
```
Първи ред
Втори ред
Трети ред
```

**Изход (output.txt):**
```
Трети ред
Втори ред
Първи ред
```

---

## Задача 2: Филтриране на студенти

Даден е текстов файл `students.txt` с формат:
```
Иван 5.50
Мария 6.00
Петър 3.50
Анна 4.25
```

Прочетете файла и запишете в нов файл `passed.txt` само студентите с оценка ≥ 4.00.

---

## Задача 3: Броене на думи

Прочетете текстов файл и отпечатайте:
- Брой редове
- Брой думи
- Брой символи (без интервалите)
- Най-дългата дума

---

## Задача 4: Двоичен масив I/O

Напишете две функции:
- `void saveArray(const char* filename, const double arr[], int size)` — записва масив от `double` в двоичен файл
- `int loadArray(const char* filename, double arr[], int maxSize)` — чете масива обратно

Тествайте с масив от 10 000 елемента. Сравнете размера на двоичния файл с текстов файл, съдържащ същите данни.

---

## Задача 5: Сортиране от файл

Прочетете числа от текстов файл, сортирайте ги и запишете обратно в същия файл. Файлът съдържа по едно число на ред.

> 🧠 **Помислете:** Можете ли да сортирате файл, без да зареждате всички числа в паметта? (Подсказка: за малки файлове — не е нужно; за големи — external sort.)
