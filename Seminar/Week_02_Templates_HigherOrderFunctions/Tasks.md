# Седмица 2 — Задачи за затвърждаване

## Задача 1: Шаблонна `swap`

Напишете шаблонна функция `swap`, която разменя стойностите на две променливи от произволен тип.

```cpp
template <typename T>
void mySwap(T& a, T& b);
```

Тествайте с `int`, `double`, `std::string`.

---

## Задача 2: Шаблонна `findMin`

Напишете шаблонна функция, която намира минималния елемент в масив:

```cpp
template <typename T>
T findMin(const T arr[], int size);
```

Тествайте с масив от `int` и масив от `double`.

> 🧠 **Помислете:** Какви изисквания поставя тази функция към типа `T`?

---

## Задача 3: Сортиране с компаратор

Напишете шаблонна функция за сортиране (bubble sort е достатъчен), която приема компаратор:

```cpp
template <typename T>
void sortArray(T arr[], int size, bool (*compare)(const T&, const T&));
```

Тествайте с:
- Сортиране на `int` във възходящ ред
- Сортиране на `int` в низходящ ред
- Сортиране на `const char*` по дължина (като компараторна функция)

## Задача 4: `forEach` с `std::function`

Напишете шаблонна функция `forEach`, която прилага операция върху всеки елемент на масив:

```cpp
template <typename T>
void forEach(T arr[], int size, std::function<void(T&)> action);
```

Използвайте я за:
1. Удвояване на всеки елемент
2. Отпечатване на всеки елемент
3. Замяна на отрицателните с 0

> 💡 Предайте различни функции (обикновени и ламбди) като `action`.
